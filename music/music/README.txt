Put real music tracks in this folder, one or more per MOOD.

Files must be seamless LOOPS (start = end), 30-120 seconds, .mp3.
Name them clearly and list them in music.json next to the app.

Example:
  music/calm-1.mp3     -> a soft ambient piano/pad loop
  music/focus-1.mp3    -> a gentle minimal loop (no vocals)
  music/sleep-1.mp3    -> a very slow drone loop
  music/energize-1.mp3 -> a light upbeat loop

License: use CC0 (public domain) recordings ONLY, so you can use them
freely with no attribution.

Good sources for CC0 music loops:
  - freesound.org   (filter license = "Creative Commons 0", search "ambient loop")
  - Pixabay music   (their own free license, commercial OK, no credit needed)
  - Incompetech     (CC-BY - requires credit, avoid unless you credit them)

The music plays LOOPED under the ambience. If no track exists for a mood,
the app falls back to its built-in generated music.
