Put your ambient recordings in this folder.

One audio file per environment, named to match samples.json.
Supported formats: .mp3, .wav, .ogg (mp3 is the best size/quality tradeoff).

Each file should be a seamless LOOP (starts and ends smooth) and ideally
30-120 seconds. They play on loop under the music.

Example:
  samples/rain-1.mp3   -> a clean rain loop
  samples/ocean-1.mp3  -> waves on a beach
  samples/fire-1.mp3   -> a fireplace crackle

License: use CC0 (public domain) recordings so you can use them freely.
Good sources:
  - freesound.org  (filter license = "Creative Commons 0")
  - archive.org    (public domain)
